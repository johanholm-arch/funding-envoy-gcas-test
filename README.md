# FundingEnvoy

An external funding platform for the pharmaceutical and medical device industry: grants, donations, sponsorships and patient-organization support. FundingEnvoy is the system of record. Its assistant, also called FundingEnvoy, prepares and checks; people decide.

This repository is being built from the design concept in `docs/concept/fundingenvoy-concept.html` and the regulatory research in `docs/research/requirements-report.md`.

Status: phase 0 in progress (demo tenant, packs, synthetic test set). See `docs/BUILD-LOG.md`.

All companies, people and figures in the demo content are fictional. Halden Pharma is the demo tenant.
